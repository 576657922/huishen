# 回神 · 方向 C「器」

**概念**：随身的精密仪器。如实画出呼吸、走神与练习，并标明每个默认值的出处。参照 Braun、Teenage Engineering 和心电图纸；暖灰与平实的中文让它不冷。

## 颜色
暖灰底 `#EFEEEA` / `#121110`，墨 `#1B1A18`；三级文字灰均达 WCAG AA（15 / 6.5 / 4.8:1）。唯一的信号色是朱 `#E5501A`（深色 `#FF6A33`），只标“此刻”：开始键指示灯、曲线上的现在、日历里的今天。

## 字体
思源黑体，子集化随包发布，各平台一致；标题 500，字距 0.04em。IBM Plex Mono 用于所有读数：等宽让跳动的数字不抖，也带出仪器感。行高 1.6，4px 基线，每屏最多 6 个字号。

## 母题
- 记录纸：呼吸曲线画在 1 秒一格的网格上，过去实线，未来虚线，朱色方块标此刻。
- 每种练习画成自己的 60 秒波形。
- 每次回神留一道刻痕。
- 身体扫描画成从脚到头的阶梯。
- 标志：“回”字即外框加中心，中心就是指示灯。

## 避开“AI 味”
- 无渐变、毛玻璃、投影、发光、emoji、色块图标、卡片网格；层级靠字号与留白。
- 图形按真实参数绘制，各屏数字对得上：第 23 轮 = 已练 04:09，剩余 05:51。
- 文案具体，如“睡着了，就当今天到这里”；依据写效应量，也写反例。
- 原生级控件：44px 触控区、安全区，结束需长按。
