# 中日文界面

首页右上角的「日本語 / 中文」切换整个应用，选择保存在现有本机偏好里。也支持 `?lang=ja` 和 `?lang=zh-CN`，供分享链接以及无法写入浏览器存储时使用。URL 中有效的语言优先，旧偏好默认中文；记录、备注、提醒里用户自己填写的文字不翻译。

`src/main.tsx` 只读取语言，然后动态加载 `src/app/boot.tsx`。必须在内容模块求值之前选好语言，因为导航、目录、引导词等会缓存模块常量。切换按钮保存偏好和 URL 后重新加载；练习进行中或暂停时不可切换，避免打断会话。刷新由用户操作触发，与 PWA 的新版本更新流程分开。

中文原文保留在 `src/content`。各内容域通过 `createTranslator` 读取对应的 `locales/ja/*.json`，使用完整原文作键；TypeScript 检查键是否存在。模板用 `{0}` 等参数，可以调整日语语序；播放器已有的 `{phase}` 等命名占位符继续交给原有格式化流程。共用短标签、错误和无障碍文案在 `auxiliary.ts`。文献标题、DOI、证据 id、练习 id、地区、号码和备份字段不因语言改变。依据卡片及其翻译维持按需加载。尚未开放的行走和睡前身体扫描引导不出现在应用中，暂未翻译。

日本語の説明文は原文の意味に沿って簡潔にしています。比較対象、研究の限界、安全上の注意を省かず、効果を強める表現にはしません。ガイドは音声ではなく文字です。求助の地域は言語から推測せず、既存の連絡先と地域表示を維持します。

日期和时长采用对应语言；节气计算继续使用原始键，日语名称仅用于展示。日文标题使用随应用发布的 Noto Serif JP 子集，正文使用设备字体，不请求外部字体或翻译服务。`npm run fonts` 同时更新中日文字体和覆盖清单。

验证：`npm run check`；`e2e/language.spec.ts` 覆盖中日文往返、偏好保留、手机与桌面布局、练习引导、不舒服面板和离线切换。`src/content/japanese.test.ts` 检查翻译占位符、求助目的地不变，以及全部已提供引导在各时长和详细程度下均能排程。
